# 恢复与维护边界

已安装专用 Recovery 的核心能力：

- 屏幕菜单：启动 Armada、重启 REC、进入 Fastboot、关机。
- 音量键移动选项，电源键确认；不依赖触摸。
- USB root shell、状态/日志读取、较长脚本传输。
- 已验证分区布局检查、离线文件系统检查、返回 Armada 并正常触摸。

菜单中存在某个入口不代表已完成所有验收；真实关机与长时间运行仍待测试。

保留原厂 boot_b、原厂 recovery_b、原厂备份与历史可用镜像。原厂 Recovery 是恢复路径，保留固件分区不表示还运行第二套 Android 系统。设备曾出现槽位回退和 GPT 空槽兼容问题，因此不能仅凭写入成功判断恢复能力。

本批公开材料不提供通用刷写或分区迁移命令。现有过程需要设备自身的原厂输入、精确布局、双份 GPT 校验、镜像回读及临时启动验证。9008/QPST 接口存在不代表已验证完整恢复包、授权或 Firehose 可用性。

当前维护规则：保留 boot_a #38；#43 仍为临时测试。新的永久安装需另行完成正常启动、桌面/游戏模式、输入、网络和恢复路径验收。不要把清理试验目录理解为允许删除原厂备份。

USB root 调试接口具有完整设备权限，面向开发维护场景；消费级版本的访问控制尚未完成审计。
