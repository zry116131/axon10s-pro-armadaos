# USB HUB 修复与验收

2026-10-16，已在原开发设备安装并验收内核 #44。主动适配随后暂停，设备进入日常体验阶段。

## 修改内容

此前工作配置将 DWC3 固定为 USB peripheral，主要服务于连接电脑调试。#44 启用 USB 双角色、PM8150B Type-C/TCPM 和 VBUS 供电控制，按原机设备树核对寄存器与电源连接；保留已验收的八核、合并 DRM、uinput 和 CPU idle 配置。

供电声明限制为 5 V / 500 mA；加入内置 xpad、joydev、Sony、PlayStation、Nintendo 和通用 USB HID 驱动。驱动已编入不等于每种手柄都已验证。USB3 PHY 和 DisplayPort 仍未启用；xHCI 出现 SuperSpeed 根 HUB 不代表物理 USB3 链路已可用。

## 实机证据

| 场景 | 结果 |
| --- | --- |
| 临时启动后连接 Mac | USB 调试重新建立，自动选择 device/sink；无线 SSH 正常 |
| 拔掉电脑，接无外部供电 HUB | 自动选择 host/source，手机为 HUB 供电 |
| USB2 HUB | `214b:7250`，480 Mbit/s 枚举 |
| 小米无线键鼠套装 2 接收器 | `2717:5055`，12 Mbit/s 枚举，创建键盘、鼠标及控制输入设备 |
| 临时启动实际操作 | 用户确认可用 |
| 固化后插着 HUB 正常重启 | 自动恢复主机角色和设备识别，用户确认画面、触摸与键鼠正常 |

当前同时连接的 Xbox 手柄走蓝牙。**有线 USB 手柄还没有实测**，不能把本轮键鼠结果等同于 Steam 游戏内手柄验收。

## 保留与后续范围

旧 #43 启动分区已完整备份；boot_b、专用 REC、原厂恢复路径和分区表保留。仅替换 boot_a，完成回读与正常重启验证。已发布的 #43 Release 保持原样。

恢复适配后可继续测试有线手柄的系统输入、Steam 菜单及游戏内操作，反向 host/device 热插拔、Type-C 插头反转、PD 供电 HUB 和休眠恢复。大功率外设、USB3、外接显示器及原生休眠不在本次通过范围内。
