# 视频候选补丁：未安装、未通过完整验收

在本项目7.2.6源码上依次应用：

1. `0005-axon-h264-input-dimensions.patch`：本机H264在bootstrap前提交已配置的输入尺寸。
2. `0006-axon-stock-h264-null-eos.patch`：保留上游旧固件分支，额外为Axon/IRIS2/精确固件1.0.90/H264会话提交NULL EOS地址。

已验证补丁顺序逐字节重建#68实际编译的vdec.c。它们不单独启用视频：仍依赖Venus内置、Iris禁用、设备树及合法原厂固件配置；固件不随本仓库分发。诊断开关不包含在这两个补丁中。

#67的EOS地址双向对照及重新启动后首次解码支持第二项兼容修改。但#68更长测试仍有早期丢帧/腐坏和快速输入结束停滞，所以不能当作稳定视频支持安装或开启Steam硬件视频解码。当前安装系统仍为#56，详情见[试验记录](../../docs/VIDEO-DECODE-TRIALS.md)。
